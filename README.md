# 마음공부

단어 하나에서 출발한 생각이 어디까지 가는지 담담하게 적어나가는 일기.
**한 권이 한 단어**이고, 하루가 한 장(page)입니다.

핵심단어는 그 권의 주제가 아니라 **생각이 시작된 자리**입니다.
`감기`는 병에 대한 책이 아니라 감기가 열어젖힌 생각이고,
`애착유형`은 검사 결과가 아니라 그 표를 본 순간에서 출발한 생각입니다.
단어는 방이 아니라 문입니다.

---

## 어떻게 돌아가는가

일기는 성격이 특이합니다. 쓰는 순간 전세계에 공개되면 담담하게 쓸 수가 없습니다.
그래서 **쓰는 곳과 읽는 곳을 분리**했습니다. 백엔드도 로그인도 없습니다.

|                            | 어디에                     | 누가 보는가 |
| -------------------------- | -------------------------- | ----------- |
| **초고** (`/write`)        | 이 브라우저의 localStorage | 나만        |
| **공개된 장** (`content/`) | git에 커밋된 마크다운 파일 | 누구나      |

흐름은 이렇습니다.

```
/write 에서 쓴다  →  .md 내보내기  →  content/단어/MM.DD.md 로 옮긴다
                                        ↓
                                     커밋 · 배포
                                        ↓
                                    누구나 읽는다
```

초고는 서버로 나가지 않습니다. `.md`로 내보내 직접 커밋할 때만 공개됩니다.

## 글 하나 추가하기

```
content/
└── 감기/                ← 한 권 = 한 단어
    ├── _book.md         ← 권 정보
    ├── 08.24.md         ← 한 장
    └── 08.31.md
```

**`_book.md`** — 권 정보 (없어도 되지만 있으면 표지가 예뻐집니다)

```yaml
---
word: 감기 # 핵심단어. 없으면 폴더명을 쓴다
slug: gamgi # URL. 없으면 폴더명을 쓴다
subtitle: 몸이 먼저 아파서야 겨우 들여다보게 된 마음 # 표지 부제
hue: 18 # 표지 색 (0-360). 없으면 단어에서 뽑는다
sat: 17 # 표지 채도(%). 기본 17, 최대 20. 낮출수록 먹색에 가까워진다
year: 2026 # 파일명에 연도가 없을 때 쓰는 기본값
sample: true # 예시 배지를 달고 싶을 때만
---
```

표지는 천을 씌운 양장본을 흉내 냅니다. 채도를 20% 위로 올리면 곧바로
책이 아니라 UI 카드처럼 보여서, 올리는 쪽은 막아두었습니다.

**`08.24.md`** — 한 장

```markdown
---
date: 2026-08-24
---

지독한 감기에 걸렸다.

월요병까지 겹친 탓일까. 몸은 들끓는데
정신은 우주를 헤엄치는 것처럼 붕 떠 있었다.

“진료확인서 필요해요?”
```

조판 규칙은 셋뿐입니다.

- **빈 줄**이 문단을 나눕니다.
- 문단 안의 **홑 줄바꿈은 그대로 살아납니다.** 호흡을 끊고 싶은 자리에 쓰세요.
- `“ ”`로 감싼 문단, 또는 `>` 로 시작하는 문단은 **인용**으로 조판됩니다.
- `**이렇게**` 감싼 부분은 강조됩니다. 인라인 표기는 이것 하나뿐입니다.

`date`를 빼면 파일명(`MM.DD`)과 `_book.md`의 `year`로 날짜를 유추합니다.

## 열람 방식

- **서재** (`/`) — `단어로` / `날짜로` 두 가지로 봅니다.
  - `단어로`: 표지가 꽂힌 책장. 최근 순 / 많이 쓴 순 / 가나다 정렬.
  - `날짜로`: 연도 → 월 스트립(글 수를 점으로 표시) → 월별 목록.
- **책** (`/book/{slug}`) — 넓은 화면에서는 펼침면 3D 넘김, 좁은 화면에서는 한 장씩 슬라이드.
  `?d=08.24`를 붙이면 그 장이 바로 펼쳐집니다.
- **목차** — 책 안에서 장을 골라 건너뜁니다.

키보드: `←` `→` `PageUp` `PageDown`으로 넘기고, `Esc`로 목차를 닫습니다.
모바일에서는 좌우로 밀어 넘깁니다.

## 펼친 횟수

권마다 몇 번 펼쳐졌는지 표지와 책 화면에 표시됩니다. **설정하지 않아도 앱은
그대로 돌아갑니다.** 숫자만 보이지 않습니다.

서버를 띄워둘 필요는 없고, 숫자를 담아둘 곳만 있으면 됩니다.

1. [Upstash](https://console.upstash.com) 에서 Redis 데이터베이스를 만듭니다 (무료 등급으로 충분)
2. REST API 탭의 두 값을 복사합니다
3. 로컬은 `.env.local`, 배포는 Vercel 프로젝트의 Environment Variables 에 넣습니다

```bash
UPSTASH_REDIS_REST_URL=https://....upstash.io
UPSTASH_REDIS_REST_TOKEN=....
```

세는 방식은 이렇습니다.

- 책을 펼치면 한 번 셉니다. **같은 세션에서 다시 열면 세지 않습니다** —
  내가 몇 번 들락거렸는지까지 세면 숫자가 금세 뜻을 잃습니다.
- 아직 아무도 펼치지 않은 책에는 숫자를 붙이지 않습니다. `0번`은 표시하지 않습니다.
- `content/` 에 실제로 있는 권만 셉니다. 없는 슬러그로 요청하면 404입니다.
- 저장소가 닿지 않아도 글 읽는 일은 막히지 않습니다. 숫자만 사라집니다.

`/api/views` 두 라우트는 요청이 올 때만 도는 함수라서 Vercel·Netlify 에서는
그대로 동작합니다. 다만 나중에 `output: export` 로 완전 정적 배포를 하면
라우트 핸들러가 죽으니, 그때는 숫자 기능도 함께 빠집니다.

## 개발

```bash
pnpm install
pnpm dev       # http://localhost:3000
pnpm check     # 타입체크
pnpm build     # 정적 생성 (content/의 각 권이 한 페이지로 빌드됨)
pnpm format
```

## 구조

```
content/                     콘텐츠. 여기만 고치면 글이 늘어난다
src/
├── app/
│   ├── page.tsx             서재 (단어/날짜 열람)
│   ├── book/[slug]/         책 리더
│   ├── write/               초고 작성
│   └── api/views/           펼친 횟수 (요청 시에만 도는 함수)
├── components/
│   ├── library/             서재 · 연대기
│   ├── book/                리더 (조판 · 넘김)
│   └── write/               원고지
└── lib/
    ├── content.ts           content/ 읽기 (서버)
    ├── parse.ts             본문 → 블록
    ├── paginate.ts          블록 → 장
    ├── drafts.ts            초고 (localStorage)
    ├── views.ts             펼친 횟수 저장소 (서버)
    └── serialize.ts         초고 → .md
```

## 조판이 정확한 이유

책처럼 보이려면 한 장에 들어갈 분량을 **픽셀 단위로** 알아야 합니다.
그래서 화면 밖에 실제와 똑같은 조판을 한 벌 더 그려놓고 각 문단의 높이를 잽니다
(`src/components/book/Measurer.tsx`).

세로 flex에서는 각 문단의 높이가 형제와 무관하므로, 덧셈만으로 정확히 나눌
수 있습니다. 행간·문단 사이·판면 높이가 모두 한 값의 배수라서, 펼침면 좌우
페이지의 줄이 같은 높이에 놓입니다.

웹폰트가 늦게 도착하면 높이가 달라지므로 `document.fonts.ready` 이후 다시 잽니다.
한 문단이 장에 다 안 들어가면, 지은이가 끊어둔 줄에서 나눠 다음 장으로 넘깁니다.

창 크기가 바뀌면 다시 조판되지만, 읽고 있던 **글**을 기억해 그 자리로 돌아갑니다.

## 나중에 붙일 것

- **클라우드 동기화** — `src/lib/content.ts`만 갈아끼우면 됩니다. 나머지는 그대로 씁니다.
- **폰에서 바로 공개** — GitHub API로 커밋하는 경로를 넣으면 됩니다. 대신 토큰 관리가 필요합니다.
